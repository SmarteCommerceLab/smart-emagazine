# Smart eMagazine

Tema WordPress editoriale sviluppato da Smart eCommerce per magazine, blog e giornali online.

## Distribuzione

Le release vengono pubblicate su GitHub e distribuite tramite Smart Repository. Il tema verifica l'integrita del pacchetto con checksum SHA-256 prima dell'aggiornamento.

## Requisiti

- WordPress 6.5 o successivo
- PHP 7.4 o successivo

Segnalazioni riservate: https://smartecommerce.it/security
